# prototype

Adapted from [emilkowalski/skills](https://github.com/emilkowalski/skills/blob/main/skills/prototype/SKILL.md). Read context, tokens and DESIGN.md; name the unresolved layout/density/motion/interaction axis.

Default three defensible working variants with realistic content, not color swaps. Show full size in context behind an instant picker. Respect reduced motion; transitions ordinarily <300ms.

Use an isolated experimental route with shared-surface ownership, or a standalone artifact outside gated product paths. Present tradeoffs. After selection integrate the choice, remove experiments and record the decision. Scope changes return to /next.
