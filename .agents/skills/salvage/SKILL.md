# salvage

Follow [CONTRACT](../CONTRACT.md) and [artifacts](../artifacts/SKILL.md). Output: `docs/research/salvage.md`.

Verify what runs the participant's work today, actual usage and paid-version capabilities. Research accessible vendor facts yourself; ask only for inaccessible workflow evidence. Start with incumbent/prior material and 1–2 alternatives; expand for decision-changing unknowns. Check current pricing, changes and meaningful complaints; reviews imply hypotheses, not prevalence. Compare buy/upgrade/build by fit, cost and constraints.

Mine used fields, transitions, exceptions, artifacts and workarounds—not navigation or feature matrices. Abandoned schema/fields reveal learning, not a prohibition on future scope. Capture baselines before an imminent upgrade.

Normalize private files/photos using [pile](pile.md); preserve provenance and uncertainty. Independent sources/pages may use salvage-miner/pile-reader with narrow inputs/output limits, or run serially.

Return sourced facts, vocabulary, entities/states, evidenced abandoned work and unresolved questions. Printed fields are not automatically necessary/legal obligations. If sources are inaccessible, report attempts and the actual gap instead of manufacturing findings.
