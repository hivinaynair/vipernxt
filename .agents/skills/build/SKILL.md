# build

Read [CONTRACT](../CONTRACT.md), AGENTS, served spine criteria, spec, ontology and scoped [requirements/contracts](../shape/requirements-readiness.md). Do not invent business fields, entities, permissions, rules or promises. Missing material policy returns to /next; internal technical choices remain yours.

Use an isolated worktree from staging. Never push to an inherited kit origin. Shared-surface slices run alone; wave 0 owns schema/routes/seed/layout. Missing foundations return to /next. Keep feature boundaries and canonical vocabulary.

Verify approved surface IDs, field validation, denials, boundaries, duplicate/conflict/recovery cases, persistence and side effects. Tests cite journey IDs. Run the AGENTS merge bar, affected production build and real critical browser path ([next-dev-loop](../next-dev-loop/SKILL.md)); missing required evidence leaves work unverified. Measure operating targets under the approved workload.

Run `bun scripts/eval.ts --require-cases`; report denominator, failures, skips and provenance. Final clip also needs `bun run check-journeys -- --complete` and combined journeys. A screenshot, citation or green exit with incomplete output is not behavior proof. Reproduce bugs before fixing.

Authorized delivery: staging PR with served steps, eval IDs, tested commit and evidence. Any later push invalidates prior evidence. Two failed repairs, repeated same-theme fixes or an unsettled product choice return to /next. Factory workers return their scoped result without a competing PR.
